v1.18.0 更新说明

【改进】音量提示改成 macOS 风格 HUD
- 半透明深色圆角面板 + 背景模糊（backdrop-filter: blur + saturate）
- 左侧喇叭图标（🔇 / 🔉 / 🔊 随音量变化）
- 中间 16 段音量柱（随音量点亮，高度递增，和系统音量条一致）
- 右侧百分比数字
- 顶部居中淡入淡出，不再是一行密集文字

【修复】全屏时不显示音量提示
- 原因：提示元素挂在 document.body 上，进入全屏后只有全屏元素内部的内容会被渲染
- 现在提示会自动挂载到当前**全屏元素**内部，全屏播放时也能显示
- 退出全屏后自动回到 body，不影响普通页面
