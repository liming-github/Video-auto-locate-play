v1.51.0 更新说明（相对上一版 1.25）

一、点击"暂停/播放"问题全面修复（1.25 → 1.51 的核心）
1. 脚本不再接管点击：以前脚本会抢走点击并与站点播放器互相抵消，导致"点了没反应"或"暂停后又自己播"；现在播放/暂停 100% 交给网站
2. 站点自动恢复播放会被压回：部分站点暂停后会自己调用 play()，现在会被识别并阻止
3. 用户主动暂停后，本页停止自动播放：不会再把暂停的视频重新拉起来
4. 站点高频反复 play() 造成的"秒播秒停"闪烁已消除
5. 站点在 pointerdown 就切换播放器的情况下，脚本不会再"补一刀"把暂停抵消

二、一个页面多个视频（新增能力）
1. 打开页面：自动定位到第一个视频并自动播放，且只定位一次，之后手动滚动不再被拽回
2. 悬停任意视频：该视频播放，其它视频全部暂停
3. 点击任意视频：该视频播放，其它视频全部暂停；再点一次则暂停它自己
4. 快捷键（←/→ 快进、↑/↓ 音量、空格、回车全屏、ESC、P 画中画）始终作用于"当前视频"，而不是页面上第一个

三、空格键与 Vimium 共存
- 检测到 Vimium 时，按空格会等 500ms：没有后续按键 = 播放/暂停；紧跟字母 = 交给 Vimium 的前缀快捷键
- 修复了按键监听重复注册导致的"一次按键处理两次"

四、音量提示（macOS 风格）
- 半透明毛玻璃面板 + 16 段音量柱 + 喇叭图标 + 百分比
- 全屏播放时同样可见（自动挂载到全屏元素内）
- 音量提示默认开启，快进/快退提示默认关闭，互不影响

五、站点例外名单
- 内置 38 条主流站点（B站、YouTube、Netflix、爱优腾、抖音、快手、小红书、豆瓣、微博、知乎、Twitch、Vimeo、Spotify 等），默认不做自动播放/定位
- 菜单可把任意站点加入/移出例外，按域名记忆
- 内置站点会明确提示"默认例外，无需加入"

六、稳定性
- 修复 1.18 误删核心函数导致的整体失效
- 修复无视频页面（列表页/文章页）被自动滚动的问题
- 修复全屏下提示不显示
- 新增自动化测试：虚拟 DOM 用例 11 组 + 真实 Chrome 鼠标事件用例 13 项
