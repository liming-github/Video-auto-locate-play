v1.52.0 更新说明

【重构】多视频行为集中成一个策略层（不再散落硬编码）
脚本顶部新增四个常量，统一控制同一时刻"只有一个当前视频"的行为：
- HOVER_DWELL_MS = 700        悬停多久才切换
- CLICK_SYNC_DELAY_MS = 150   点击后多久同步"其它暂停"
- USER_QUIET_MS = 1500        用户操作后多久内不自动播放
- SWITCH_GUARD_MS = 3000      刚暂停后多久内悬停不触发

【行为总览】
1. 进页面自动定位第一个视频并播放，只做一次
2. 悬停任意视频 ≥700ms → 它播放，其它全暂停
3. 点击任意视频 → 站点先处理；150ms 后若在播，其它全暂停
4. 快捷键只作用于当前视频
5. 用户暂停过 → 本页停止自动播放；操作后 1.5s 内不自动播

【文档】docs/MULTI-VIDEO.md 归纳了多视频站点的 4 种关系（独立型/互斥型/懒加载型/iframe 型）
以及统一策略，新站点按表对号入座即可，不需要按域名加规则。

【自测】真实浏览器 13/13、jsdom 11 组全部通过。
